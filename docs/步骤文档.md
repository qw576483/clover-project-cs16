> **本文件是唯一总纲**。agent 之间不许私自改契约；发现契约有问题 → 先回报主 agent。

## 0. 目标与一句话验收

**目标**：Unity 6 工程 `clover-project-cs16/client` 打开点 Play 即跑：启动画面 → 主菜单 → New Game（选 de_dust2 + bot 数量 + 3 档难度）→ 读条 → 选阵营 → de_dust2 里用第一人称打一整场比赛（买枪 → 交战 → 下包/拆包 → 回合结算 → 半场换边 → 比赛结束 → 回主菜单），全程有 HUD / 买枪菜单 / H 菜单 / 记分板 / 音效，机器人 3 档难度行为可辨。

**验收**：`策划/验收表.md` 全表填满，且每格 ≥2 条独立证据（日志 + 截图，截图自己读过）。

## 3. 关键契约速查（写代码前必看）

### 3.1 引擎真实 API（已核对源码，**不许编**）
- 启动：`Game.Launch(new GameConfig{...})` → `CloverRes.Init("Assets/Resources")` → `CloverInput.Init()`；**单机不调 `CloverNet.Init`**（`Game.Net == null` 是正常的，业务别碰它）。
- UI：`Game.UI.Open<T>(param)` / `Close<T>()` / `CloseAll()` / `Get<T>()` / `IsOpen<T>()` / `Confirm(title,msg,onOk,onCancel,okText,cancelText)` / `Toast(text,dur)` / `FloatText(pos,text,color,dur)`；面板预制体必须在 `Resources/UI/{类名}`；`UIPanel` 可覆写 `OnOpen(param)` / `OnClose()` / `OnUpdate(dt)` / `Layer`（`UILayer.Background/Normal/Popup/Top/System`）。
- 代码搭 UI：`CloverEngine.UIFactory.CreateNode/Stretch/CreateCentered/CreatePanel/CreateText/CreateButton/DefaultFont/UICamera`。
- 输入：`Game.Input.GetKey/GetKeyDown/GetKeyUp(GameKey)`、`GetMouseButton(0/1/2)`、`GetMouseButtonDown/Up`、`MouseDelta`、`State.MoveDirection`、`Lock()/Unlock()`。**禁止直连 `UnityEngine.Input` 或 `Keyboard.current`**。
- 相机：**没有第一人称相机** → 业务自写（`Game.Camera.Follow` 是锁 Z 的简单跟随，**FPS 不许用它**）。
- 射线：**引擎不提供** → 用 Unity `Physics.Raycast`（业务自写）。
- 动画：`Game.Anim.CreateAnimator(go, RuntimeAnimatorController)` → `IAnimPlayer.Play/CrossFade/SetFloat/SetBool/SetTrigger/OnComplete`。`AnimatorController` 只能用 Editor 脚本生成。
- 音效：`Game.Sound.PlaySFX(name)` / `PlaySFXAt(name, pos)` / `PlayBGM/StopBGM` / `SetVolume(SoundGroup, v)`；路径约定 `Sound/SFX/{name}`（走 `Game.Res`）。
- 资源：`Game.Res.LoadAsset<T>(path, cb)` / `TryGet<T>(path)`（读已驻留）/ `Preload(list, onDone, progress)`。**禁止 `Resources.Load`**。
- 对象池：`Game.Pool.Spawn(key,parent,group)` / `Despawn` / `Preload(key,count)` / `ClearGroup(group)` / `GetActiveCount(key)`。
- 实体：`Game.Entity.Create(objectID, typeID, group)` / `BindView` / `GetView` / `DestroyGroup(group)` / `ClearAll()`。
- 定时器：`Game.Timer.After/Every/AfterUnscaled/EveryUnscaled/AfterName/EveryName/StopScope/Stop`（暂停画面里走时间要用 `Unscaled`）。
- 事件：`Game.Event.On/On<T>/Off/OffAll/Emit/Emit<T>/Emit<T1,T2>`（**Off 必须同一方法引用**，不许用匿名 lambda 注册长驻订阅）。
- FSM：`Game.Fsm.RegisterState(state,onEnter,onTick,onExit)` / `AddTransition(trigger,to)` / `Trigger` / `Force` / `Current`。
- 场景：`Game.Scene.Load(name, onProgress, onDone)` / `Unload(name, onDone)` / `CurrentScene`。
- 设置：`Game.Setting.Get<T>(key,def)` / `Set<T>(key,v)` / `Save()` / `Load()`。
- 地图：`Game.Map.LoadFromResource("MapData/de_dust2", cb)` → 读 `Assets/Resources/MapData/de_dust2.bytes`；`Game.Map.Loaded` / `WalkableAt(x,z)` / `Status`。
- 局域网：`Game.LanBrowser.Scan()` / `Hosts` / `OnHostFound` / `OnScanFinished`（单机扫不到是**正常真实行为**，不是降级）。
- 日志：`Game.Logger.Info/Warn/Error(tag, msg)`。**禁止裸 `Debug.Log`**。

### 3.2 分层铁律（`reference/architecture.md`，交付前跑自检）
- `App → Module → Core → Def`；**UI 不许 `using` 任何 `Module.*`**（只发/收事件 + `Game.UI.Open<T>`）。
- 模块之间只经**接口**协作（App 注入），禁止 `FindObjectOfType` / `GameObject.Find` / 单例互找。
- 不按预期走的分支**必须打日志**（出错返回/判空/校验失败/`switch default`/资源加载失败）。

### 3.3 本工程约定
- 命名空间：`Cs16.Core` / `Cs16.Module.<Xxx>` / `Cs16.UI` / `Cs16.App`。
- 所有 UI 面板走 `Game.UI.Open<T>()`，预制体放 `Assets/Resources/UI/{类名}.prefab`，**由 Editor 脚本生成**（不许手写 .prefab YAML）。
- 数值一律来自 `CsConst` / `CsWeapons`，**禁止在业务脚本里写裸数字**。
- 场景名一律来自 `SceneNames`，事件名一律来自 `Events`。

## 4. 步骤清单与串并行

```
【阶段 0】主 agent：探环境 / 定契约 / 工程创建 / manifest（已完成）
     ↓
【阶段 1 ★并行】agent-01（壳与流程）  +  agent-03（比赛核心）  +  agent-02（地图几何与烘焙）
     ↓  （三者只依赖契约，互不碰目录）
【阶段 2 ★并行】agent-04（操作与射击）  +  agent-05（机器人 AI）  +  agent-06（游戏内 UI）  +  agent-07（视图与音效）
     ↓
【阶段 3】主 agent：装配检查 + 编译 + 场景/预制体生成 + 进 Play 实测 + 截图自审 + 填验收表
     ↓
【阶段 4】对照 CS 1.6 逐项自审（不像就返工）→ 交付说明 + 资源欠缺清单
```

| 步骤 | 产出 | 验收 | 前置 |
|---|---|---|---|
| S1 | 工程可编译、Boot/Menu 场景生成、菜单链路可走 | Play 能进主菜单 | — |
| S2 | de_dust2 场景 + `.bytes` 烘焙 | `Game.Map.Loaded==true` 且障碍数>0 | — |
| S3 | `CsMatch` 可跑完整一场（bot 互相打） | 日志显示回合推进与比分 | 契约 |
| S4 | WASD 移动 + 鼠标转视角 + 射击命中 | Play 里能打死 bot | S1,S2,S3 |
| S5 | 3 档 bot 行为可辨 | 三档命中率/反应时间日志有差异 | S3 |
| S6 | 全部面板可开可关 | 逐个面板截图 | S1,S3 |
| S7 | 角色/武器视图 + 枪声/脚步 | 画面有模型、开枪有声 | S2,S3 |

## 5. 风险与未知（主 agent 跟踪）

| # | 风险 | 处置 |
|---|---|---|
| R1 | de_dust2 布局全手工摆坐标，工作量大 | agent-02 用"布局数据表 → 批量生成 Box"的方式，先保证**连通性与地标**，再补细节 |
| R2 | 引擎无 FPS 相机/无射线 API | 明确属 **C 桶（业务自写）**，agent-04 用 Unity 原生 `CharacterController`/`Physics.Raycast` |
| R3 | 单机下 `Game.Net == null` | 业务禁调 `Game.Net.*`；装配期不调 `CloverNet.Init` |
| R4 | 预制体只能用 Editor 脚本生成 | 每个 agent 自带 `Assets/Editor/**` 生成器；由主 agent 用 unity-cli 驱动执行 |
| R5 | 首次 Play 前后端输入差异 | 输入一律走 `Game.Input`；`Application.runInBackground = true` 写在 Bootstrap.Awake |
| R6 | 快速进入 Play 模式导致第二次全蓝 | 交付前用 Editor API 关掉 `enterPlayModeOptionsEnabled` |
| R7 | 资源（模型/音效）不一定下得到 | 按 A→同源→CC0 兜底→占位 四级链；占位必须在 `client/资源欠缺清单.md` 登记 |

## 6. 日志要求（所有 agent）

**凡是"没按预期走"的分支必须留一条日志**：出错返回 / 兜底判空 / 参数校验失败 / 非法状态 / `switch default` /
资源加载失败 / 反序列化失败 / 高频回调里的异常（防刷屏：只报一次或降频）。
客户端一律 `Game.Logger.Info/Warn/Error(tag, msg)`，tag 用模块名（如 `"Match"` / `"Bot"` / `"Flow"`）。
