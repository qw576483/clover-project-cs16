# agent-59 · 取「原版 CS 1.6 实机参照物」（一切 1:1 对比的前置）

## 为什么先做这个
用户判定：**"动画 / 特效 / 界面 / UI / 手感 / 各种感官都不一样，毫不相干"**。
此前所有工作都是**局部数值 + 局部截图**自证，**从未做过"原版 vs 我们"的整体对比** —— 而对比必须有参照物。
⚠️ **用户没有原版游戏**（他本人说的）⇒ 参照物只能从**公开渠道**取（实机截图、录像、比赛录像、教程视频等）。

## 目标：拿到可逐项对比的原版画面/录像，并按维度切好
1. **收集**（穷尽，≥4 轮不同关键词 × ≥3 类站点）：
   - 原版 CS 1.6 的**实机截图**：主菜单、选阵营/选兵种页、买枪菜单、HUD（含雷达/血量/金钱/弹药/击杀信息）、计分板、控制台、回合结束面板；
   - **地图/角色**：de_dust2 各点位视角、9 个兵种模型（正面/背面/侧面）、第一人称持枪视角（各武器）；
   - **表现/特效**：枪口火焰、弹痕、血、死亡、换弹、（若有）爆炸与烟雾；
   - **录像**：比赛/实况里能看出**移动节奏、准星行为、后坐力、切枪、跳跃**的片段（手感只能用录像判）。
2. **落盘与命名**：`原版资源/参照物/<维度>/<名字>`（维度：`menu` / `hud` / `buy` / `class` / `map` / `roles` / `viewmodel` / `fx` / `video`）。
   - 每件记：**来源 URL + 抓取时间 + 分辨率 + 内容一句话**（账 `原版资源/参照物/清单.md`，append-only）；
   - 视频只留**片段/抽帧**（别把整部片搬进来；抽帧落 `原版资源/参照物/video/<片名>/f###.png`）。
3. **⚠️ 分辨率与版本要标清**：原版默认 **640×480 / 800×600**，也有 1024/1280 的社区截图；还有 **Steam 版 / 非 Steam 版 / CZ** 的区别 ⇒ 每件标清"分辨率 + 版本 + 是否有 HUD 缩放"。**不同版本的 HUD 布局不同**，混用会把对比做错。

## 硬约束
1. ⛔ 不改引擎、⛔ 不改 skill、⛔ **不碰 `client/**`**（本片只做参照物采集）。
2. 写入范围：`原版资源/参照物/**`、`.ai-tmp/**`。
3. ⛔ **不许把自己工程的截图混进参照物**（那是"我们"不是"原版"）—— 每件必须能从 URL 追到来源。
4. 命令显式超时；超 15 分钟把进度落盘 + 给 `main` 一条回报（**第一行写模型标识**）。
5. 取不到的（例如原版不同分辨率的 HUD 布局差异）⇒ **如实列"缺什么"**，⛔ 不许拿"看起来像"的顶替。

## 回报（`send_message` 给 `main`）
① 各维度件数（`menu/hud/buy/class/map/roles/viewmodel/fx/video`）+ 逐维度一行短结果；② 分辨率/版本覆盖面（哪些分辨率有、哪些没有）；③ 清单路径；④ 缺什么（拿不到的维度逐条列）。⛔ 不填表、⛔ 不建矩阵。
