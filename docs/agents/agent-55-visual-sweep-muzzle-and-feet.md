## 为什么这一片（用户原话）
用户说："**枪口火焰我 b51 只是给你举例子而已**……你看看**所有枪的火焰**和**右脚**有没有啥问题。"
⇒ 前序片只把 `m249` 的十字火焰当样板修了，**其余武器的火焰没有逐个看过**；用户还要看**角色右脚**。
⇒ 本片 = **发现式巡检**：逐个看、逐条记异常。**不是**按已有判据验收。

## 任务 A：全部武器的枪口火焰（逐把开火 + 近景）
- 武器清单以工程武器表为准（`Core/CsWeapons.cs` 自己读，**≥20 把**：`glock18 usp p228 deagle fiveseven elite mp5 tmp mac10 ump45 p90 galil famas ak47 m4a1 sg552 aug scout awp g3sg1 sg550 m3 xm1014 m249 knife …`）。
- **每把至少一张近景**（开火瞬间，机位固定在枪口侧前方），落 `.ai-tmp/screenshots/sweep-muzzle/`（命名含武器名）。
- **逐把记**（这是产出）：
  - 有没有火焰？位置在枪口吗（不是手/枪身/半空）？大小是否随武器变化（原版不同枪的火焰尺寸不同）？贴图是不是原版那张（不是纯色块/方块/十字错位）？是否有**残留/不消失/闪烁**？
- 已知事实（别重造）：引擎只 precache **3 张** `muzzleflash1/2/3`；`hw.dll` 里的选择例程 `idx=(arg%10)%3`、**参数由调用方给**，`client.dll`/`mp.dll` **全文 0 处 `muzzle`** ⇒ 原版"哪把枪用哪张"的**表不在盘上**。⇒ **本片不看表，只看画面**：把"看起来不对"的逐把列出来（异常清单比归因更重要）。

## 任务 B：角色脚部 / 右脚
- 巡检对象：**9 个兵种模型**（`player_T` / `player_T_{leet,arctic,guerilla}` / `player_CT` / `player_CT_{gsg9,sas,gign,vip}`）+ 本地玩家自己。
- 机位：**正面 + 侧面 + 背面**近景（能看到脚与地面接触）+ **走动中**（走/跑/蹲各一段）与**静止**。
- **逐条记异常**：右脚（以及左脚）有没有 —— 穿地/悬空/反折/错位/贴图错/不跟着动画动/只动一只/骨骼拉长/鞋底贴地不实？走路时脚步是否交替、滑步、抖动？
- ⚠️ **两种"脚"都要看**：① **第三人称**角色的脚（新换的 9 个 mdl ⇒ 骨骼/权重可能有问题）② **第一人称**画面里自己的脚/腿是否异常出现或缺失。
- 落 `.ai-tmp/screenshots/sweep-feet/`。
