**⚠️ 一条影响全部引用的口径风险**：盘上这份 `mp.dll` 是 **ReGameDLL 系构建**（`game_version=5.28.0.756-dev`，含 `mp_round_infinite` / `mp_hegrenade_penetration` / `mp_afk_bomb_drop_time` 等专有 cvar），**不是 Valve 官方 1.6 的那一份**。⇒ 引它的数值时必须注明来源；**默认值**（如 `mp_hostagepenalty=13`）恰是社区版最可能改过的地方，凡 Valve 原版另有出处者以 Valve 为准。

**两条可复用的扫描口径**（`mpdll-scan` 实测踩出来的，后续任何反汇编片都会用到）：
1. **绝对位移的收录范围**：只收"基址寄存器为 0 的绝对位移"会**漏掉 `mov eax,[eax+0x101A1590]` 这类"寄存器基址 + 指向 `.data` 的绝对 disp"读** —— 它因此一度把奖金表误判成死数据。正确口径 = **收任何 `0x10000000 ≤ mem.disp < 0x10200000` 的位移**。
2. **静态 `cvar_t` 本身就是运行时对象**（注册处只 `push <结构体 VA>; call [...]`，不回存指针）⇒ 要找某个 cvar 的使用者，**搜「条目 VA + 0xC」**即可（用它定位到 `CBasePlayer::AddAccount @ 0x100683D0`、`m_iAccount = player + 0x1CC`、按 `mp_maxmoney->value` 截顶）。

**三条已采纳的结论**（登记于 `#117~#123`）：

1. **回合常量的"两套口径"都合规，不该改** —— 1:1 复刻的对象是**玩家实际生效的那一套**（随包 `server.cfg` 覆盖后的值），出厂默认只是同一个 cvar 的未覆盖态；工程 `CsConst` 顶部已写明两套并存且不混用，现状是清一色随包口径。⇒ 本项**不是差异**（登记 `#122`）。
2. **C4 蜂鸣是唯一确认的机制性错误**（`#118`）：奖金 / 连败 / 部位倍率 / 拆包时长均属"工程本来就对"。
3. **`#119` 是一份「工程本来就对」的清单**（8 个奖金常量 + 连败三件套 + 4 条部位倍率 + 拆包 5/10，全部与盘上字节一致）—— **反向证据同样登记**，避免后人把"已知正确"当成"没人验过"再翻一遍。

**仍未取到（7 项，如实收、不续派）**：下包耗时 / `flArmorRatio`·`flArmorBonus` / HE 伤害半径引信 / 闪光致盲时长 / 烟雾时长体积 / 首响 `m_flNextFreqInterval` 初值 / 工程 `RewardBombDefuse=300` 的来源。前 6 项卡在"不在 .text 或需另找载体"，第 7 项已登记 `#120`（22 格表里确实没有 300）。

## 四、**根因：原版出处的载体塌了**

三个域同时撞到同一堵墙，这也是"继续往下做"的第一顺位问题：

1. 文档反复引用的 **`原版资源/cs16src/cs16game/app/cstrike/server.cfg`**、**`.../cstrike/settings.scr`**、**`原版资源/解包产物/原版数值表.md`** —— **三份全部不在盘**（已登记 `#96`）。
2. 对照表 N-01~N-35 引用的 `mp.dll` 偏移来自**另一份副本**（1,316,152 B 的 `cs16game/app`），而盘上这份是 `原版资源/cs16src/cstrike/dlls/mp.dll`（**1,640,960 B**）。同批文档里的 `WeaponInfo[]` 偏移**已被实测证伪**（文档说基址 `0x10f708`，实为字符串 `common/npc_step1.wav`；真表在 `.data file 0x163CD8`、步长 `0x28`）。
3. `原版资源/hlsdk/` 只有 **10 个文件**（`dlls/weapons.cpp` 一份 + `cl_dll/*` + `pm_shared/pm_shared.c` + `common/ref_params.h`），**没有 `combat.cpp` / `grenade.cpp` / `player.cpp`**。

⇒ **所以"照文档改数"是危险的**：文档里的偏移不可信、引用的文件不存在。正确顺序是 **先在盘上这份 `mp.dll` 里重新定位并复证**（`mpdll-scan` 正在做），取不到就**如实登记取不到**。
