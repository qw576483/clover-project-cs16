# 项目总纲 · clover-project-cs16（单机版 Counter-Strike 1.6）

> 用 [Clover 客户端引擎](https://github.com/qw576483/clover-client-unity-engine) **1:1 复刻《反恐精英 1.6》单机模式**的工程。
> 参考游戏 A = **CS 1.6**；形态 = **单机**（不接服务端，本地开图 + 机器人，与官方 New Game 一致）。
> 规格真源：`策划/策划案/CS1.6单机参考规格.md`；逐项对照：`策划/对照表.md`；验收：`策划/验收表.md`；外观差异：`策划/外观差异清单.md`。

---

## 0. 目标与一句话验收

**目标**：Unity 6 工程 `client` 打开点 Play 即跑：启动画面 → 主菜单 → New Game（选 de_dust2 + bot 数量 + 3 档难度）→ 读条 → 选阵营 → de_dust2 里用第一人称打一整场比赛（买枪 → 交战 → 下包/拆包 → 回合结算 → 半场换边 → 比赛结束 → 回主菜单），全程有 HUD / 买枪菜单 / H 菜单 / 记分板 / 音效，机器人 3 档难度行为可辨。

**验收口径**：1:1 硬标准六维 —— 布局按原版像素 / 素材必须是 A 原版 / 字体照原版 / 色调不加滤镜 / 交互反馈 / 节奏；`策划/对照表.md` 每行「原版值（出处）/ 我们的值 / 差值 = 0」。画面与 UI 不像原版 ⇒ 该版本不可交付。

**交付形态三段缺一不可**：① 启动与菜单链路 ② de_dust2 首场景完整版 ③ 游戏内流程（暂停 · 设置 · 回主菜单 · 退出）。

## 2. 工程结构

| 路径 | 内容 |
|---|---|
| `client/` | Unity 工程（复刻本体；`Library/` `Temp/` `Logs/` 等生成物不入库） |
| `策划/` | 本总纲、规格、对照表、验收表、外观差异清单、原版基线图、`images/` 实机图 |
| `tools/` | 判据与工具：编译检查、探针与量法脚本 |
| `原版资源/` | 原版素材与解包数据（含 `参照物/`、`清单.md`） |

`client/Assets/` 分层（依赖方向单向，**UI 不许 `using` 任何 `Module.*`**）：

```
App  →  Module  →  Core  →  Def
          │           │
          └── UI 经事件 + Game.UI.Open<T> 协作（不直接引用 Module）
```

| 目录 | 职责 |
|---|---|
| `Scripts/App/` | 启动装配、模块注册、场景流程 |
| `Scripts/Module/` | `Flow` 流程 / `Map` 地图 / `Match` 比赛 / `Player` 操作 / `CameraRig` / `Combat` 战斗 / `Bot` AI / `View` 视图 / `Audio` 音效 |
| `Scripts/UI/` | 面板（Flow 菜单类 / InGame 局内类），预制体由 Editor 脚本生成 |
| `Scripts/Core/` | 常量、武器表、事件名、枚举（**数值唯一来源**） |
| `Scripts/Def/` | 消息号与协议定义（本项目单机，仅保留形态） |
| `Editor/` | 场景 / 地图 / 预制体 / Animator 生成器 |

## 3. 关键契约（写代码前必看）

| 文件 | 内容 |
|---|---|
| `Assets/Scripts/Core/CsEnums.cs` | `CsTeam` / `CsRoundPhase` / `CsRoundEndReason` / `CsBotDifficulty` / `CsWeaponClass` / `CsWeaponSlot` / `CsHitbox` / `CsTeamLimit` |
| `Assets/Scripts/Core/CsConst.cs` | 全部数值常量 + `SceneNames` + `PhysicsLayers` |
| `Assets/Scripts/Core/CsWeapons.cs` | 武器表（32 把，含价格/伤害/射速/后坐力/击杀奖励） |
| `Assets/Scripts/Core/CsMatchConfig.cs` | `CsMatchConfig` / `CsPlayerSettings` |
| `Assets/Scripts/Core/Events.cs` | 全部事件名常量 |
| `Assets/Scripts/Module/Match/CsTypes.cs` | `CsActor` / `CsKillEvent` / `CsRoundEndInfo` / `CsHitInfo` / `CsBotProfile` / `CsBotIntent` / `CsBotState` |
| `Assets/Scripts/Module/Match/ICsMatch.cs` | 比赛门面（**核心契约**）+ `CsInputState` + `CsHitboxProxy` |
| `Assets/Scripts/Module/Map/ICsMap.cs` | 地图门面 + `CsMarkers` |

**分层铁律**：`App → Module → Core → Def`；模块之间只经**接口**协作（App 注入），禁用 `FindObjectOfType` / `GameObject.Find` / 单例互找。

**本工程约定**：

- 命名空间：`Cs16.Core` / `Cs16.Module.<Xxx>` / `Cs16.UI` / `Cs16.App`。
- 所有 UI 面板走 `Game.UI.Open<T>()`，预制体放 `Assets/Resources/UI/{类名}.prefab`，**由 Editor 脚本生成**（不许手写 `.prefab` YAML）。
- 数值一律来自 `CsConst` / `CsWeapons`，**禁止在业务脚本里写裸数字**；场景名来自 `SceneNames`，事件名来自 `Events`。
- 日志：`Game.Logger.Info/Warn/Error(tag, msg)`，tag 用模块名（`"Match"` / `"Bot"` / `"Flow"`）；**禁止裸 `Debug.Log`**。
- 禁令 API：`PlayerPrefs` / 裸 `Input` / `GameObject.Find` / `FindObjectOfType` / `Instantiate(` / `Resources.Load`（例外须在 `策划/验收表.md`「允许的差异」登记）。
- 资源路径收敛到 `Core/ResPaths.cs`；一次性产物只放 `.ai-tmp/`，不进 `Assets/`。

## 4. 引擎能力速查（已核对源码，**不许编**）

- 启动：`Game.Launch(new GameConfig{...})` → `CloverRes.Init("Assets/Resources")` → `CloverInput.Init()`；**单机不调 `CloverNet.Init`**（`Game.Net == null` 是正常的）。
- UI：`Game.UI.Open<T>(param)` / `Close<T>()` / `CloseAll()` / `Get<T>()` / `IsOpen<T>()` / `Confirm(...)` / `Toast(...)` / `FloatText(...)`；`UIPanel` 可覆写 `OnOpen` / `OnClose` / `OnUpdate` / `Layer`。
- 代码搭 UI：`CloverEngine.UIFactory.CreateNode/Stretch/CreateCentered/CreatePanel/CreateText/CreateButton/DefaultFont/UICamera`。
- 输入：`Game.Input.GetKey/GetKeyDown/GetKeyUp(GameKey)`、`GetMouseButton(0/1/2)`、`MouseDelta`、`State.MoveDirection`、`Lock()/Unlock()`；禁止直连 `UnityEngine.Input`。
- 相机 / 射线：**引擎不提供 FPS 相机与射线** → 用 Unity 原生 `CharacterController` / `Physics.Raycast` 自写。
- 动画：`Game.Anim.CreateAnimator(go, RuntimeAnimatorController)` → `IAnimPlayer.Play/CrossFade/SetFloat/SetBool/SetTrigger/OnComplete`；Controller 只能用 Editor 脚本生成。
- 音效：`Game.Sound.PlaySFX(name)` / `PlaySFXAt(name, pos)` / `PlayBGM/StopBGM` / `SetVolume(SoundGroup, v)`，路径约定 `Sound/SFX/{name}`。
- 资源：`Game.Res.LoadAsset<T>(path, cb)` / `TryGet<T>(path)` / `Preload(list, onDone, progress)`；禁止 `Resources.Load`。
- 对象池：`Game.Pool.Spawn/Despawn/Preload/ClearGroup/GetActiveCount`。
- 实体：`Game.Entity.Create(objectID, typeID, group)` / `BindView` / `GetView` / `DestroyGroup` / `ClearAll`。
- 定时器：`Game.Timer.After/Every/AfterUnscaled/EveryUnscaled/AfterName/EveryName/StopScope/Stop`（暂停画面里走时间必须用 `Unscaled`）。
- 事件：`Game.Event.On/On<T>/Off/OffAll/Emit/Emit<T>/Emit<T1,T2>`（`Off` 必须同一方法引用，长驻订阅不许用匿名 lambda）。
- FSM：`Game.Fsm.RegisterState/AddTransition/Trigger/Force/Current`。
- 场景：`Game.Scene.Load(name, onProgress, onDone)` / `Unload` / `CurrentScene`。
- 设置：`Game.Setting.Get<T>(key, def)` / `Set<T>(key, v)` / `Save()` / `Load()`。
- 地图：`Game.Map.LoadFromResource("MapData/de_dust2", cb)` → `Assets/Resources/MapData/de_dust2.bytes`；`Game.Map.Loaded` / `WalkableAt(x, z)` / `Status`。
- 局域网：`Game.LanBrowser.Scan()` / `Hosts` / `OnHostFound` / `OnScanFinished`（单机扫不到是正常行为）。
- 日志：`Game.Logger.Info/Warn/Error(tag, msg)`。

## 5. 复刻纪律

- **A 有 ⇒ 做；A 没有 ⇒ 不加**：不做手感优化、不做自创 UI、不做"看起来合理"的补齐。
- **写不出出处的量不许进工程**：几何 / 坐标 / 尺寸 / 颜色 / 数值 / 公式 / 字体 / 时长都要有出处（参考物 `文件:行` / 资源文件 / 规格条款）。
- 素材只用 A 自己的：`原版资源/` 下解析搬运，禁止重写与近似替代；载体拿不到按降级链逐级退并登记。
- 占位物 / 纯色块 / 默认 UI / OnGUI 调试文字 / "留钩子后续替换" 一律不算完成。
- 不按预期走的分支必须留日志；发现问题就地修，不攒成"已知问题清单"。
- 首页画面底部必须有一行 `by clover-engine`。
