## 0. 一级来源（原版客户端本体）的尝试结果 —— ★ 必须看

**任务书首选**：跑项目内原版客户端本体
`原版资源/cs16src/cs16game/app/hl.exe -game cstrike`，在原生 1920×1080 采 4 类图。

### 实测：跑不起来，卡在 **Authorization（Steam 鉴权接口）** 阶段

| # | 试过的启动方式（原话） | 结果 | 证据 |
|---|---|---|---|
| 1 | `hl.exe -game cstrike -w 1920 -h 1080`（工作目录 = `app`） | 进程活着，但弹 **`Fatal Error`** 对话框，正文逐字：**`Failed to initalize authentication interface. Exiting...`** | 截屏 `.ai-tmp/test/a21shots/boot/t010.png`（已删）｜窗口标题实测 `Fatal Error` |
| 2 | `launcher.exe -game cstrike -w 1920 -h 1080`（repack 自带启动器，标题 `Counter-Strike Launcher`，`Source Engine Launcher / LiON`） | 启动器 GUI 正常；**自动点 `Play Counter-Strike`（窗口内 (218,272)）后**，`hl.exe` 起来了，**同一个 Fatal Error** | 截屏 `.../launcher/t012.png`、`.../play1/t030.png`（已删） |
| 3 | 同上 + `+map de_dust2` | **同一个 Fatal Error**（连地图加载都没到） | `.../play1/t075.png`（已删） |

**卡在哪（逐条实测，不是"没试"）**：

1. 报错串在**引擎**里：`authentication` 在 `hw.dll` / `sw.dll` / `swds.dll` 各命中 6 次、`SteamAPI_Init` 各 1 次；
   `hl.exe` / `hlds.exe` 命中 **0** ⇒ 失败点在渲染器 DLL 的 Steam 初始化，**不是渲染器选择问题**
   ⇒ 换 `-soft`（软件渲染 `sw.dll`）**同样会失败**，故未浪费时间试。
2. 该 repack 用的是 **RevEmu（REVOLUTiON）** 模拟器：`app/steamclient.dll`（392,704 B）内含
   `RevEmu` / `rev.ini` / `Steam_ConnectToGlobalUser` / `REVOLUTiON`；`app/steam.dll`、`hwpatcher.dll` 同源；
   `app/config/rev_masterservers.vdf` 亦为 RevEmu 产物。原版真身被备份成 `steamclient_orig.dll` / `steam_orig.dll`。
3. **RevEmu 从未初始化**：跑完 3 次，`app/` 下**没有任何新增文件**（`rev-client.log` 不存在，`Get-ChildItem` 今日 mtime = 0 个）
   ⇒ 失败发生在"加载模拟器"之前或未走 RevEmu 路径。
4. RevEmu 的配套启动器 **`revLoader.exe` 不在盘上**（`app/` 全量列目录 39 个文件，无此项）；
   `hwpatcher.dll` **无导出表**（PE 导出目录 = 0）⇒ 没有可由外部调用的 patch 入口。
   `hw.dll` 与 `hw.dll.orig` 同尺寸（1,840,440 B）但 **SHA256 不同**（`CD0C019F…` vs `6543B7B0…`）⇒ 已被改过，但改动**没有**绕过鉴权。
5. 本片**不许写** `原版资源/**`（任务书 §4 白名单只有 `策划/基线图/**`、`策划/外观差异清单.md`、`策划/对照表.md`）
   ⇒ 不能补 `rev.ini` / 换 `hw.dll` 再试。

**结论**：这不是"兼容/显卡"问题，是 **repack 的授权链缺件**。谁能给 → **用户**（或换一份可直接启动的原版客户端）。
⛔ 按 skill 三条铁律第 3 条：**不许自己画**，故退到降级链（见 §1）。
